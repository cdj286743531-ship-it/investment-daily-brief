# 信源使用指南 | Source Guide

## 第一优先级（官方权威）

### 中国政府机构
- **中国证监会** (www.csrc.gov.cn) - 政策、公告、监管动态
- **中国人民银行** (www.pbc.gov.cn) - 货币政策、利率、逆回购
- **国家统计局** (www.stats.gov.cn) - GDP、CPI、PMI 等经济数据
- **外汇管理局** (www.safe.gov.cn) - 外汇政策、跨境资金流动

### 国际机构
- **SEC** (www.sec.gov) - 美股公司公告、财报、内幕交易
- **Federal Reserve** (www.federalreserve.gov) - 美联储利率决议、会议纪要
- **Bloomberg** (www.bloomberg.com) - 全球金融市场数据
- **Reuters** (www.reuters.com) - 国际财经新闻

### 交易所
- **上交所** (www.sse.com.cn) - A 股公告、指数数据
- **深交所** (www.szse.cn) - A 股公告、指数数据
- **港交所** (www.hkex.com.hk) - 港股公告、指数数据
- **NYSE/NASDAQ** - 美股行情、公司公告

### 财经媒体（权威）
- **财联社** (www.cls.cn) - 7x24 小时财经快讯
- **Wind** (www.wind.com.cn) - 金融数据终端
- **华尔街见闻** (wallstreetcn.com) - 全球财经资讯

## 搜索策略

### 关键词组合

**A 股市场**：
```
"A 股 收盘 涨跌" + "上证指数 深证成指"
"板块 领涨 领跌" + "资金流向"
"财报 业绩 超预期" + "Q4 年报"
```

**港股市场**：
```
"恒生指数 收盘" + "恒生科技"
"港股通 资金流向"
"腾讯 阿里巴巴 业绩"
```

**美股市场**：
```
"S&P 500 NASDAQ close" + "Fed rate"
"earnings beat miss" + "guidance"
"analyst upgrade downgrade" + "price target"
```

**宏观经济**：
```
"央行 逆回购 MLF LPR"

```

### 时间过滤

- **日内新闻**：`tbs=qdr:d`（过去 24 小时）
- **周度总结**：`tbs=qdr:w`（过去 7 天）
- **月度数据**：`tbs=qdr:m`（过去 30 天）

## 信源验证

### 交叉验证原则

1. **单一信源不发布**：重要新闻至少 2 个独立信源
2. **官方优先**：以官网、公告为准，媒体报道为辅
3. **追溯源头**：转载新闻追溯至原始来源

### 虚假信息识别

❌ **避免使用**：
- 无作者、无来源的自媒体文章
- 标题党（"震惊"、"重磅"、"突发"但无实质内容）
- 只有结论没有数据支撑的分析
- 来源模糊的"业内人士透露"

✅ **优先使用**：
- 交易所官方公告
- 公司官网新闻稿
- 财报原文（10-K、10-Q、年报）
- 央行、统计局等官方数据
- 权威财经媒体（财新、财联社、路透、彭博）

## 数据引用规范

### 格式要求

```markdown
【标题】事件摘要【来源】

示例：
【央行】今日开展 1000 亿元 7 天期逆回购，利率 2.3%【中国人民银行】
【财报】腾讯 Q4 营收 1559 亿元，同比增长 10%，超预期【腾讯控股公告】
【评级】高盛上调腾讯目标价至 450 港元【高盛研报】
```

### 链接要求

- 必须提供可点击的原始链接
- 避免使用短链接、重定向链接
- 优先使用官方域名链接

## 特殊场景处理

### 财报季

**重点关注**：
1. 营收、净利润是否超预期
2. 毛利率、净利率变化趋势
3. 现金流状况
4. 管理层指引（guidance）

**数据来源**：
- 美股：SEC EDGAR 数据库
- A 股：交易所官网
- 港股：港交所披露易

### 并购重组

**验证要点**：
1. 交易金额、对价方式
2. 是否需监管审批
3. 完成时间表
4. 协同效应分析

**信息来源**：
- 交易所公告
- 公司官方新闻稿
- 监管机构批文

### 高管变动

**关注级别**：
- CEO、CFO、董事长变动（必须报道）
- 核心业务负责人变动（选择性报道）
- 独立董事变动（通常不报道）
